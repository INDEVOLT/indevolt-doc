# BK1600

:::info[Périmètre]
Ce firmware est publié par série de produits et non nommé d’après un modèle unique. Les modèles suivants d’une même série partagent le même ensemble de firmwares :

**Indevolt BK1600**

Le paquet de firmware contient les firmwares des modules CMS, Pfile, EMS, BMS, MPPT, INV. Chaque module est mis à jour indépendamment ; consultez la section correspondante selon vos besoins.
:::
