# 旁路口接微逆调控说明

旁路口（Backup）接入微型逆变器（微逆）后，系统根据并网 / 离网状态采用不同调控策略：

- **离网**：通过调整输出频率，主动降低微逆发电功率。
- **并网**：同步电网运行，不调节微逆功率；检测到逆流或过载时断开旁路保护。

## 1. 离网接微逆：频率调控降功率

### 1.1 为什么要调频？

离网运行时，系统自行维持供电，失去电网的功率缓冲能力，若微逆发电功率超过负载消耗，直流母线电压会持续升高，超出安全范围后系统将触发保护停机。

### 1.2 调控逻辑

系统通过提高输出频率来降低微逆出力 —— 微逆检测到频率升高后，会自动按比例减少发电功率，使发电量与负载消耗重新达到平衡。整个过程自动完成，无需人工干预。

### 1.3 固件限制

离网接入微逆需 EMS **1.01.05 或更高版本**，功率范围 **30 W ~ 1200 W**。SOC 低于 3% 时暂停响应微逆输入，恢复后自动响应。详细说明参考 [旁路口使用说明](https://link.wtturl.cn/?target=https%3A%2F%2Fdocs.indevolt.com%2Fzh%2Fdocs%2Fhardware%2Ftechnical-note%2Fbypass&scene=im&aid=582478&lang=zh)。

## 2. 并网接微逆：同步电网，异常断开旁路

### 2.1 正常运行

并网状态下设备输出与电网同频同相，微逆跟随电网运行，系统**不主动调节**微逆功率。微逆发电量优先供给负载和电池充电，多余电量在馈网限制内可馈网。

不同用能模式下的能源分配逻辑，参考 [旁路口使用说明](https://link.wtturl.cn/?target=https%3A%2F%2Fdocs.indevolt.com%2Fzh%2Fdocs%2Fhardware%2Ftechnical-note%2Fbypass&scene=im&aid=582478&lang=zh)。

### 2.2 保护机制

检测到以下任一异常时，系统立即断开旁路口，15 分钟后自动恢复：

| 触发条件 | 阈值                                 |
| -------- | ------------------------------------ |
| 逆流超限 | 超出最大馈网功率 10%，持续超过 30 秒 |
| 微逆过载 | 输入功率超过 2400 W，持续超过 30 秒  |

断开后微逆失去电网连接，停止发电；恢复后系统重新检测，异常仍存在则再次断开。

## 3. 两种模式对比

| 对比项   | 离网接微逆                | 并网接微逆          |
| -------- | ------------------------- | ------------------- |
| 调控方式 | 主动调频降功率            | 同步电网，不调节    |
| 微逆功率 | 受设备频率控制            | 跟随电网自行输出    |
| 异常保护 | 过压停机 / SOC 低暂停响应 | 逆流 / 过载断开旁路 |
| 功率范围 | 30 W ~ 1200 W             | 不超过 2400 W       |
| 适用场景 | 停电、无市电地区          | 正常接市电使用      |

## 4. 常见问题

**Q1：离网调频会影响家电正常使用吗？**

A：不会。调频范围控制在安全区间内，调节过程平缓，普通家电不受影响。

**Q2：并网时为什么不调频降功率，而是断开旁路？**

A：并网时电网频率固定，设备无法通过频率干预微逆出力，因此采用异常即断开的保护策略，响应更快。

**Q3：旁路断开后多久恢复？**

A：15 分钟后自动恢复。若异常仍存在，会再次断开。

## 5. 备注

1. 本文档适用于 PowerFlex 2000 / SolidFlex 2000 系列。
2. 离网调频需微逆支持频率 - 功率响应，使用前请确认兼容性。
3. 所有参数为典型值，实际以固件版本和现场设置为准。
