# 收益计算方式说明

在 Indevolt App 中，您可能会看到"今日收益"、"光伏收益"、"储能收益"等数据。这些数字是怎么算出来的？

简单理解：系统通过对比"如果没有光伏和储能，您要花多少钱"和"现在实际花了多少钱"，中间的差额就是您获得的收益。

## 1. 收益从哪里来

安装光伏和储能系统后，您的收益主要来自三个方面：

- 💰 **少买电**：光伏发电直接供家里使用，或电池在需要时放电，减少从电网买电。
- 💵 **卖电**：家里暂时用不完的电送入电网，获得售电收入。
- 🧠 **用电更聪明**：储能把电留到更需要或电价更高的时候使用，相当于"低价存、高价用"。

## 2. 系统如何计算收益

系统会设想三种家庭用电情况，通过互相比较，分别估算出光伏和储能各为您创造了多少收益。

### 对比场景

| 对比情况         | 假设条件                | 费用含义                                         |
| ---------------- | ----------------------- | ------------------------------------------------ |
| ① 都不装         | 没有光伏、没有储能      | 所有家庭用电都从电网购买，需要花的钱             |
| ② 只装光伏       | 只有光伏、没有储能      | 光伏发电供家里使用，但没有电池帮忙时，需要花的钱 |
| ③ 都装了（实际） | 光伏 + 储能（实际情况） | 根据实际购电和售电情况，计算出的当前实际费用     |

**收益公式：**

- **光伏收益** = ①的电费 − ②的电费（装光伏后省了多少）
- **储能收益** = ②的电费 − ③的电费（装电池后又多省了多少）
- **家庭总收益** = 光伏收益 + 储能收益

## 3. 家庭总收益的两种理解方式

总收益有两种常见说法，计算结果一致，看您习惯哪种。

|          | 光伏收益 + 储能收益                                          | 节约电费 + 售电收入                          |
| -------- | ------------------------------------------------------------ | -------------------------------------------- |
| 适合场景 | 看光伏和电池各贡献多少；光伏、储能详情页分别展示；评估投资回报，对比用能策略 | 看少交了多少电费、卖电赚了多少；自己核对账单 |

其中"节约电费 + 售电收入"也可以写成：

**家庭总收益 = 没有光伏和储能时的费用 − 当前实际费用**

其中：**当前实际电费 = 购电量 × 购电价 − 售电量 × 上网电价**。

如果是基本不向电网售电的家庭：售电收入为 0，总收益 ≈ 节约电费。

> **信息**
> 售电收入只是收益的一部分。光伏发电被家里直接用掉、电池放电减少购电，这些"少买电"省下的钱同样是收益。

以 2026 年 8 月 20 日为例，用 App 中的真实数据演示收益计算过程。

### 查看收益结果

在 App 的"收益计算器"页面，可以看到当日收益：

- 光伏收益：0.39€
- 储能收益：0.12€
- 总收益：0.51€

计算关系：**0.39 + 0.12 = 0.51**，即总收益 = 光伏收益 + 储能收益。

### 收益计算过程

系统通过对比三种场景的电费，分别算出光伏收益和储能收益：

| 项目     | 计算方式                               | 结果                    |
| -------- | -------------------------------------- | ----------------------- |
| 光伏收益 | 不装光伏时的电费 − 只装光伏时的电费    | 0.39€                   |
| 储能收益 | 只装光伏时的电费 − 光伏 + 储能时的电费 | 0.12€                   |
| 总收益   | 光伏收益 + 储能收益                    | 0.39 + 0.12 = **0.51€** |

> 三种场景的具体电费由系统后台模拟，App 不直接展示。

### 另一种理解方式

总收益也等于节约的电费加上售电收入，需要用到购电量、售电量和电价数据。

> **注意**：App 中的收益为估算值，与电力公司最终账单可能存在差异，详见下方FAQ。

## 5. 分时电价如何计算

如果您所在地区不同时段电价不同（即分时电价），系统会按各时段分别计算后再汇总：

**某时段实际费用 = 该时段购电量 × 该时段购电价 − 该时段售电量 × 该时段上网电价**

## 6. 哪些情况下收益计算可能不准确

以下情况可能导致系统无法准确计算收益：

- 有存量光伏电量，但未进入家庭能源系统记录。
- 没有独立、准确的电池功率或电量数据。
- 没有配置完整的购电电价或上网电价。
- 关键设备数据缺失，或计量方向配置错误。

## 7. FAQ

### 为什么不是"发电量 × 电价"？

光伏发出的电可能被家里直接使用、给电池充电或卖给电网，不同用途的价值不同，所以不能只用一个乘法简单计算。

### 为什么我自己算不出储能收益？

储能收益需要和"只有光伏、没有储能"的情况对比。这个场景在现实中没有单独发生，需要系统根据设备数据进行模拟估算。

### 为什么售电收入不等于总收益？

售电收入只是收益的一部分。您还会因为光伏发电被家庭直接使用、电池放电减少购电等原因而节约电费，这部分也是收益。

### 为什么 App 收益和电费账单不完全一样？

App 展示的是根据设备数据和已配置电价计算的能源收益。电力公司账单还可能包含基本电费、税费、阶梯电价、补贴或其他结算项目，因此两者可能存在差异。

### 为什么当天收益后来发生了变化？

常见原因是设备数据稍晚上传、电价更新，或系统完成补算。请以数据完整后重新计算的结果为准。

### 为什么收益有时候是负数？

一般是"高充低放"导致的——电价高时从电网买电充电，电价低时放电使用。
