# EMC指南

## 1. 关于 EMC

**EMC（电磁兼容）** 是电子设备的一项重要电磁性能，主要包括两个方面：既不会对周围其他设备造成明显的电磁干扰，自身也能够在一定的电磁环境中正常工作。

本产品已依据相关安全及 EMC 标准进行符合性评估。其中，产品安全相关标准主要包括 EN/IEC 62109系列和 EN/IEC 62477-1等；EMC相关标准主要包括 ETSI EN 301 489系列和 EN IEC 61000-6系列。这些标准从产品安全、电磁发射和电磁抗扰度等方面对设备提出相应要求。

在正常使用条件下，所有带电运行的设备都会产生微弱电磁场。储能设备在运行时，可能对附近依靠天线接收信号的无线电类设备产生轻微影响，例如收音机出现轻微杂音。这属于设备运行过程中可能出现的 EMC 正常现象。

## 2. 现象

如果您在使用中遇到以下情况，可能与 EMC 有关：

家里的短波收音机、广播收音机等设备，原来接收正常，但在安装储能设备后，出现声音断续或轻微的“沙沙”杂音。

**通常不会受到明显影响的设备：**

| 设备类型 | 说明 |
|---|---|
| 设备自身的无线通讯 | 微储本机的 Wi-Fi、蓝牙、4G 等通信功能正常使用不受影响；如出现 App 连接不稳定等问题，请联系售后排查 |
| 其他常见电子设备 | Wi-Fi 路由器、电脑、手机等常见数字类设备不受影响，可正常使用 |


## 3. 遇到相关现象，可以这样处理

如果您遇到了上述现象，可以按以下顺序尝试：

**① 从设备侧减少影响**

- 将储能设备的交流线、PV 线尽量捆扎成束、缩短走线，避免绕圈；
- 在线缆上加装铁氧体磁环（套在线缆上的抑制器件，可用于降低部分高频干扰）；
- 将收音机等设备远离储能设备及功率线缆，或调整天线位置。

**② 过滤电源线上的信号（终端处理）**

如果影响是通过电源线传播的，可以在受影响设备的电源输入端加装一个电源 EMI 滤波器（插在设备电源线前面的小装置，用于过滤线路中的电磁信号）。

## 4. 说明与备注

以上方法可用于初步排查和处理。如果处理后问题仍存在，请联系售后，由专业人员进一步排查。
