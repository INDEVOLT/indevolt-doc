# 微储 RCD 安装说明

## 1. 什么是 RCD？

RCD（Residual Current Device，剩余电流保护装置），也称为漏电保护器，是一种用于保护人员和设备安全的电气保护装置。

正常情况下，电流会沿火线（L）和零线（N）形成完整回路流动。当设备或线路发生异常漏电时，例如：

- 设备内部绝缘损坏；
- 电流流向设备外壳；
- 人员接触带电部分；

部分电流会通过非正常路径流向大地，导致火线和零线中的电流不平衡。RCD 可以检测这种异常电流，并在达到保护条件时自动切断电源，降低触电和设备损坏风险。

简单来说：

- **正常情况下**：电流正常流动，RCD 保持接通；
- **发生漏电时**：RCD 检测到异常电流，并自动断开电路。

---

## 2. 为什么微储需要 RCD？

微储系统包含：

- 电池系统；
- 逆变器；
- 交流输入/输出接口；
- （部分设备）光伏输入接口。

设备内部包含大量电力电子器件，在异常情况下可能发生漏电。RCD 可以检测漏电情况，在发生漏电风险时及时切断电源，提高系统安全性。

---

## 3. 连接方式

```mermaid
flowchart LR
    GRID[家庭电网] --> MCB1[空气开关]
    MCB1 --> RCD1[RCD<br/>漏电保护器]

    subgraph ESS[微储]
        GRID_PORT[GRID IN/OUT]
        BACKUP_PORT[Backup]
    end

    RCD1 --> GRID_PORT

    BACKUP_PORT --> MCB2[空气开关]
    MCB2 --> RCD2[RCD<br/>漏电保护器]
    RCD2 --> LOAD[负载]
```

**并网输入侧**

家庭电网连接微储 GRID IN/OUT 时：

- RCD 用于保护微储交流输入/输出回路；
- 当交流侧发生漏电时，RCD 可以切断电源。

**Backup 输出侧**

微储 Backup 输出连接负载时：

- 建议在 Backup 输出侧安装独立 RCD；
- 用于保护备用供电回路中的人员和设备安全。

---

## 4. 离网接地注意事项

### 浮地输出

当系统采用浮地输出方式，即输出端 N（零线）与 PE（保护地）之间没有连接：
- 第一次漏电可能无法形成有效故障电流路径；
- RCD 可能无法立即检测并动作；

### N-PE 单点接地

通过在输出侧设置 N-PE 单点连接：
- 可以建立系统接地参考；
- 设备外壳漏电时，可以形成故障电流路径；
- RCD 可以更可靠地检测漏电并切断电源。

---

## 5. RCD 类型选择

RCD 根据能够检测的漏电类型不同，主要分为 A 型和 B 型。

INDEVOLT 微储兼容 A 型和 B 型 RCD。为获得更全面的漏电保护能力，**推荐使用 B 型 RCD**。

| 类型          | 可检测漏电类型                                                      | 适用场景                                                                 |
| ----------- | ------------------------------------------------------------ | -------------------------------------------------------------------- |
| A 型 RCD | - 正弦交流漏电<br />- 脉动直流漏电                                         | - 普通家庭插座回路<br />- 普通家庭用电设备，如冰箱、洗衣机、白炽灯等<br />- 不含光伏逆变器、EV 充电桩、变频空调等设备的回路 |
| B 型 RCD | - 正弦交流漏电<br />- 脉动直流漏电<br />- 平滑直流漏电<br />- 高频交流漏电<br />- AC/DC 混合漏电 | - 光伏逆变器<br />- 储能系统<br />- EV 充电设备<br />- 含变频驱动的设备                         |
