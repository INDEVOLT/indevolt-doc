# SFA/PFA_G2

:::info[Toepassingsbereik]
Deze firmware wordt per productserie uitgebracht en is niet benoemd naar een enkel model. De volgende modellen binnen dezelfde serie delen dezelfde firmware:

**SFA1800, PFA2000**

Het firmwarepakket bevat de firmware van de modules BMS SLAVE, DCDC. Elk module wordt afzonderlijk bijgewerkt; raadpleeg indien nodig het betreffende gedeelte.
:::
